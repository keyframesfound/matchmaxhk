Tutors pay MatchMax’s matching admin fee. Parents and centres never pay MatchMax a matching fee.

| Situation | Admin fee (tutor pays) |
| --- | --- |
| Private (B2C) — each enrolled student / case | **1.5 lessons** (100% L1 + 50% L2) |
| Partner centre intro — 1st student | **1.5 lessons** |
| Same centre, within 6 months — 2nd student | **1.0 lesson** |
| Same centre, within 6 months — 3rd student | **0.5 lesson** |
| Same centre, within 6 months — 4th+ | **$0** |
| Short package ≤5 lessons | **20% of package** |

Max about **3.0 lessons** per centre introduction, then free at that centre. Private siblings stay full 1.5 each (no household step-down).
