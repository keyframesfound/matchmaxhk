Most tutoring problems are scheduling problems in disguise. This guide covers the full cycle: confirming dates, running gentle reminders, moving lessons when life happens, and what to do when you are sick or the student does not show up. The scripts are copy-paste ready.

## Confirming dates

When a parent agrees a date and time in chat, message MatchMax Admin so the lesson is on the calendar. The chat agreement is the start; the calendar entry is the confirmation. Then confirm again the day before, so both sides walk into Lesson 1 knowing exactly when and where.

## Gentle reminders and punctuality

- Prepare 10 minutes before every lesson, especially for in-home sessions where travel and setup eat time.
- Keep a consistent Zoom link and pin it in the chat, so nobody hunts for a link at lesson time.
- Send gentle reminders for the next lesson without nagging: a short message the day before is enough.

## Last-minute reschedules

- If a parent asks to move a lesson, offer two make-up options promptly. Giving choices keeps momentum and shows flexibility.
- If you must move a lesson, give as much notice as you can. Families plan around your slot, and early notice keeps goodwill high.

## Tutor sick days

Waking up sick is not a failure; leaving the family in silence is. Message the parent as early as you can, apologise once, and give them options rather than a flat cancellation. Use this script:

```script
# Tutor sick: same-day notice to the parent
--en
Good morning [Parent Name], I woke up with a fever/bad cough today and want to be careful not to pass anything on to [Student Name]. Could we either (A) run today's [Time] lesson on Zoom if you prefer not to break momentum, or (B) move our in-person lesson to [Option 1 Day/Time] or [Option 2 Day/Time]? Apologies for the sudden adjustment!
--zh
[家長稱謂]早晨！唔好意思，我今朝起身有啲發燒／感冒咳，為免傳染畀 [同學名]，想同你商量下今日 [時間] 嘅課堂：我哋可以 (A) 轉用 Zoom 照常上堂保持進度，或者 (B) 改去 [選項一 日期/時間] 或 [選項二 日期/時間] 補返面授課堂？唔好意思要臨時調動！
```

Offering a Zoom option first protects the student's momentum; the two make-up slots give the parent control. If you are too unwell to teach at all, say so plainly and prioritise the make-up date.

## Student no-show

If the student does not show within 20 minutes of the start time, message the parent, then wait for a reply before releasing the slot. Two scripts cover the sequence:

```script
# Student no-show: 20-minute check-in
--en
Hi [Parent Name], we were booked for [Student Name]'s lesson at [Time] but I have not been able to reach anyone for 20 minutes. Are you still able to make it? If today is difficult, I can offer [Option 1 Day/Time] or [Option 2 Day/Time] as a make-up.
--zh
[家長稱謂]你好！[同學名] 今日 [時間] 嘅堂已經過咗 20 分鐘，我哋都聯絡唔上你哋，想問下係咪照常上堂？如果今日唔方便，我可以安排 [選項一 日期/時間] 或者 [選項二 日期/時間] 補堂。
```

If there is still no reply after waiting, send one closing message and move on with your day:

```script
# Student no-show: releasing the slot
--en
Hi [Parent Name], I waited 20 minutes but could not reach anyone, so I will use the time for lesson prep and see you at our next scheduled slot. If you would still like a make-up this week, message me and we will find a time.
--zh
[家長稱謂]你好，我等咗 20 分鐘都聯絡唔上你哋，今日會先用時間備課，下堂見。如果今個星期想補堂，話我知，我哋再約時間。
```

## When a parent goes quiet

If a parent stops responding, follow up once, politely, and then ask MatchMax for help rather than chasing repeatedly. And a rule worth repeating: do not treat an unconfirmed booking as agreed. A slot exists only when the parent has confirmed it in chat and it is on the calendar.
