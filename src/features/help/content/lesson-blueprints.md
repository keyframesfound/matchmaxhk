# Teaching Tactics, Lesson Blueprints, and Resource Vault

Strong tutors do not simply explain more. Strong tutors structure learning so the student carries more of the thinking over time, transferring the regulatory burden from instructor to student.

## The 60-Minute Lesson Blueprints

**Blueprint A: First Lesson Conversion Script**

| Time | Phase | Tutor action | Outcome |
| :--- | :--- | :--- | :--- |
| **0-5 mins** | Ice-Breaker | Establish rapport. Avoid opening textbooks immediately. Confirm the goal discussed before the lesson, such as school pacing, confidence, exam target, or topic concern. | Student feels seen before being assessed. |
| **5-20 mins** | Low-Stakes Diagnostic | Give a curated 3-question quiz on recent school topics. Observe thinking without rushing to correct every step. | Specific bottleneck identified. |
| **20-45 mins** | The Quick Win | Choose one correctable error from the diagnostic. Scaffold the solution until the student experiences a clear improvement. | Visible progress created inside Lesson 1. |
| **45-60 mins** | Exit & Parent Pitch | Assign targeted homework. Speak with the parent immediately after and explain the diagnostic finding in plain language. | Parent understands value and next step. |

**Blueprint B: Standard Four-Phase Ongoing Lesson**

| Phase | Duration | Action | Tutor focus |
| :--- | :--- | :--- | :--- |
| **1. Retrieval Warm-Up** | 0-10 mins | Give a 3-question low-stakes quiz on previous content. | Memory, confidence, and gap detection. |
| **2. Modeling** | 10-25 mins | Introduce the target concept using an "I Do" think-aloud. | Show how expert thinking works. |
| **3. Scaffolding** | 25-45 mins | Use collaborative "We Do" practice and gradually reduce help. | Transfer thinking to the student. |
| **4. Exit Ticket** | 45-60 mins | Student completes one unseen question independently. Review errors and assign homework. | Check independent readiness. |

## Zimmerman's Self-Regulated Learning (SRL) Cycle

Self-regulated learning represents the active application of metacognitive knowledge. Tutors should intervene at each phase to build independent learners:

| SRL Phase | Cognitive Mechanisms | Tutor Coaching Strategies |
| :--- | :--- | :--- |
| **Forethought Phase** | Task analysis, strategic planning, goal setting, and activation of self-efficacy beliefs before the activity begins. | Model how to dissect a prompt. Force the student to articulate a specific plan of attack and set clear, measurable micro-goals before starting. |
| **Performance Phase** | Deployment of specific learning strategies, self-control, and continuous self-monitoring during the task. | Observe the student working and interject with process-oriented questions ("Why did you choose that formula?"). Ensure they do not drift into automatic, thoughtless execution. |
| **Self-Reflection Phase** | Evaluating the outcome against goals and attributing success/failure to controllable factors. | Guide the student to analyze errors without emotional judgment. Explicitly link outcomes to the strategies chosen during Forethought, rather than innate intelligence. |

## Gradual Release of Responsibility (GRR)

Application rule: Support should fade as student thinking increases. This mitigates the risk of overloading working memory.

| Phase | Tutor role | Student role | Example |
| :--- | :--- | :--- | :--- |
| **I Do (Modeling)** | Demonstrates the concept using a comprehensive think-aloud protocol. | Observes the thinking process and cognitive schema. | Tutor solves an algebra equation and explains why x is isolated first. |
| **We Do (Scaffolding)** | Provides hints, graphic organizers, and contingent fading of support. | Collaborates and takes on more cognitive load. | Tutor writes the first line; student writes the next. |
| **You Do (Mastery)** | Observes, checks, and prompts reflection. | Completes the task independently without environmental cues. | Student completes an unseen past-paper question. |

## Concrete-Representational-Abstract (CRA) Sequence

For STEM subjects, systematically build conceptual depth before introducing procedural rules. Begin with physical reality before moving into abstract symbols.

| Stage | Description | Example |
| :--- | :--- | :--- |
| **Concrete** | Physical or visual representation. For online lessons, use Virtual-Representational-Abstract (VRA) dynamic digital manipulatives (e.g., PhET). | Blocks, balance scale, counters, manipulatives. |
| **Representational** | Diagram, drawing, model, or tape diagram. Acts as a cognitive bridge to encode physical experiences into a symbolic format. | Sketches, bar models, annotated diagrams. |
| **Abstract** | Equations, formulas, and symbolic notation. Introduced stripped of intimidation factor. | 2x + 3 = 7 |

## Content and Language Integrated Learning (CLIL) & EMI Bridging

If a student thinks in Cantonese but is assessed in English (EMI), employ deliberate linguistic scaffolding:

- Maintain a two-column vocabulary sheet (e.g., Isomerism / 同分異構).
- Allow concept explanation in Cantonese first when it secures understanding.
- Provide extensive visual aids and realia to anchor verbal explanations in reality, reducing linguistic cognitive load.
- Guide the student into academic English after the mechanism is clear, utilizing structured sentence starters for evaluations.

## Error-Diagnostic Taxonomy

| Error type | Meaning | Tutor response |
| :--- | :--- | :--- |
| **Conceptual Deficit** | The student does not understand the idea | Reteach with concrete or visual explanation |
| **Execution / Process Error** | The idea is understood but steps go wrong | Slow the process, mark error points, drill targeted steps |
| **Deciphering Deficit** | The student misreads the question or command word | Teach command words, annotation, and question unpacking |

## PEEL+ Essay Construction

Each analytical paragraph should include:

| Component | Function | Prompt |
| :--- | :--- | :--- |
| **P - Point** | State the argument clearly | What is the paragraph proving? |
| **E - Evidence** | Use relevant evidence | What detail supports the point? |
| **E - Explanation** | Explain how the evidence proves the point | Why does the evidence matter? |
| **L - Link** | Connect back to thesis or question | How does this answer the question? |
| **+ - Marking Objective** | Make the assessment skill visible | Which criterion is being demonstrated? |
