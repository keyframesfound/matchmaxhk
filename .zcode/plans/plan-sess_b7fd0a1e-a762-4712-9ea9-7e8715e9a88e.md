## Goal

Make the header/search collapse scroll-scrubbed instead of threshold-triggered: as soon as the user starts scrolling, the search bar shrinks away while the top nav buttons slide up and out, continuously tracking scroll position (and reversing smoothly on scroll-up). Applies automatically to `/` (main tutor page), `/tutors`, `/tutor-requests`, and `/courses` since they all share the same components.

## Files to change

1. **`src/components/search/sticky-search-group.tsx`** — the core rework:
   - **Measure `pinStart`**: the scroll offset at which the band reaches the header (band's document offsetTop via the offsetParent chain, minus live `headerTop`). Re-measure via the existing ResizeObserver pattern. On the homepage this is ≈0, so the animation begins with the first scroll pixel.
   - **Continuous progress**: `useScroll()` (motion/react, already a dep) → `rawProgress = useTransform(scrollY, [pinStart, pinStart + 140], [0, 1], { clamp: true })`, then `displayProgress = useSpring(rawProgress, { stiffness: ~500, damping: ~50 })` — near-1:1 tracking that irons out scroll jitter (this is the "more smooth"). While `phase === "expanded"`, raw is forced to 0 (band stays open; exiting expanded springs it closed).
   - **Context change**: expose `collapseProgress: MotionValue<number>` alongside the existing `phase`/`headerTop`/`expand`/`collapse`. The scroll listener shrinks to just the expanded-exit rule (scroll down >4px while tinted → collapse); the direction-threshold top/compact logic and `CompactPillSlot`'s AnimatePresence spring are removed.
   - **`StickySearchBar`**: outer wrapper becomes a `motion.div` with `overflow-hidden` whose height scrubs from the measured content height → 0; the inner div keeps bg + `border-b` and fades out over the last ~40% of progress, with `pointer-events-none`/`aria-hidden` past 50%. Net visual: the bar shrinks into the header while the page rises. Scrim/expand behavior unchanged. Reduced motion → near-instant spring config.
2. **`src/components/layout/SiteHeader.tsx`** — consume `collapseProgress`:
   - Nav tabs: `motion.nav` slides up out of the header (`y` 0 → −72 over progress 0→0.55, clipped by `overflow-hidden` on the centering wrapper) with opacity fading 0.3→0.55 — "nav buttons move up" instead of a plain fade.
   - Compact pill: the center slot scrubs in (rises from below, `y` 28 → 0, fading in over progress 0.45→0.85) replacing the pop spring; pointer-events on/off via a `useMotionValueEvent` threshold state (~0.5) for both nav and pill.

No route-file changes needed — `index.tsx` (already migrated in the working tree), `tutors.index.tsx`, `tutor-requests.index.tsx`, `courses.index.tsx` all inherit the new behavior. Before deleting `CompactPillSlot` I'll grep for other usages.
