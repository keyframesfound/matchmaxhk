# Add the Legal Warning to the tutor profile score section

**Target assumption (stated explicitly):** "the score page" = the public tutor profile page `/tutors/$tutorCode`, which is where exam scores are displayed (the "Academic Performance" section). The score-entry side (/join) already carries this exact warning at the top of `ApplicationForm.tsx`, so the profile page is the only score page missing it.

## Changes

### 1. `src/routes/tutors.$tutorCode.tsx` — render the warning

Inside the Academic Performance `ProfileSection` (after the exam results list, ~line 681), append the same alert treatment used on the join form, fed from i18n:

```tsx
<p className="flex gap-2.5 rounded-md border-l-2 border-destructive bg-destructive/5 px-3 py-2 text-sm leading-relaxed text-foreground">
  <AlertTriangle className="mt-0.5 h-4 w-4 shrink-0 text-destructive" aria-hidden="true" />
  <span>
    <span className="font-bold text-destructive">
      {translate("profile.legal_warning_label")}
    </span>{" "}
    {translate("profile.legal_warning_body")}
  </span>
</p>
```

- Add `AlertTriangle` to the existing lucide-react import.
- It lives inside the `examResults.length > 0` conditional, so it only appears on profiles that actually show scores (no empty-state clutter).
- Flat, border-based styling per design conventions (no shadows).
