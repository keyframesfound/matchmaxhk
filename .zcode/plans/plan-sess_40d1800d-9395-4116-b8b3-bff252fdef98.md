# Add a share button to the tutor card

## Approach

Add a self-contained share icon button inside `PublicTutorCard`'s footer icon cluster, styled identically to the existing compare-toggle button (h-10 w-10 rounded-sm icon button with tooltip, no shadows). It reuses the existing `shareOrCopy()` utility and appears on every public card automatically (home, directory, saved posts, similar-tutors rows).

## Changes

### 1. `src/features/tutors/public-tutor-card.tsx`
- Import `Share2` from `lucide-react` and `shareOrCopy` from `@/lib/share`.
- Add prop `shareable?: boolean` (default `true`) so the admin preview can hide the button.
- Add a `handleShare` that calls `event.stopPropagation()` (so the card's click-to-open doesn't fire), then `shareOrCopy(...)` with:
  - `title`: `` `Tutor ${formatTutorCode(tutor.tutor_code)} | MatchMax` ``
  - `text`: `` `Check out tutor ${tutor.tutor_code} on MatchMax — HK$${tutor.hourly_rate}/hr.` `` (same copy as the detail page's share)
  - `url`: `` `${window.location.origin}/tutors/${tutor.tutor_code}` ``
  - copied message: `t("profile.link_copied")` (existing key: "Profile link copied" / "已複製個人檔案連結")
- Render the button in the footer's icon cluster between `saveAction` and `footerAction`, wrapped in `TooltipProvider`/`Tooltip` exactly like the compare toggle: `Share2` icon, `aria-label={t("tutor_card.share", { code })}`, `onKeyDown` stopPropagation, same hover/focus classes (`text-[color:var(--ink)]/55 hover:bg-[color:var(--foreground)]/[0.06] hover:text-[color:var(--ink)]`).

### 2. `src/features/tutors/admin/TutorEditor.tsx`
- Pass `shareable={false}` on the "Live Card Preview" card instance so admins don't get a live share action in the editor preview.

### 3. i18n — both locale files
- `src/features/i18n/locales/en.json`: add `"share": "Share tutor {{code}}"` under `tutor_card`.
- `src/features/i18n/locales/zh-HK.json`: add `"share": "分享導師 {{code}}"` under `tutor_card`.
- No new toast key needed — reuse `profile.link_copied`.

## Verification
- `npx tsc --noEmit`
- `npx eslint` on the touched files
- `npm run check:i18n` (key parity en/zh-HK)

No dependency changes, so `bun.lock` is untouched.
